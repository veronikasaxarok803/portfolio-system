## Шкала шрифтів

Кожен зразок використовує справжній клас токена, тому висота рядка, трекінг і жирність береться з `@theme`.

export const scale = [
  { token: "text-display", font: "font-display", sample: "Veronika Haran" },
  { token: "text-title", font: "font-display", sample: "Ideas made tangible." },
  { token: "text-heading", font: "font-display", sample: "Good ideas deserve thoughtful design." },
  { token: "text-subheading", font: "font-display", sample: "Forma — a quieter kind of web" },
  { token: "text-body", font: "font-body", sample: "I help startups and solo entrepreneurs turn their ideas into clean, modern websites and apps that work. Українська: швидка бура лисиця." },
  { token: "text-label", font: "font-ui", sample: "INDEPENDENT UI/UX & WEB DESIGNER" },
  { token: "text-button", font: "font-ui", sample: "EXPLORE MY WORK" },
  { token: "text-logo", font: "font-ui", sample: "vh" },
  { token: "text-arrow", font: "font-body", sample: "↗" },

<Unstyled>
  <div className="flex flex-col gap-6 text-ink">

## Відступи

Окремих токенів немає: беремо кроки 8, 12, 16, 24 і 32 px (у Tailwind числа 2, 3, 4, 6 і 8).

export const steps = [2, 3, 4, 6, 8];

<Unstyled>
  <div className="flex items-end gap-6">
    {steps.map((n) => (
      <div key={n} className="flex flex-col items-center gap-2">
        <div className="bg-accent" style={{ width: `calc(var(--spacing) * ${n})`, height: `calc(var(--spacing) * ${n})` }} />
        <code className="font-ui text-label text-ink-muted">p-{n}</code>
      </div>
    ))}
  </div>
</Unstyled>
